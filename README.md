# BigScopeScatter
[Fiji](https://fiji.sc/) plugin to build cytofluorograms (2D histograms or scatter plots) of large images with linear/log scaling.  
Specific areas (ROIs) on the scatter plot can be selected and reconstructed back to a corresponding images.


It is in the work-in-progress state (especially documentation).   
You can try [to install](https://github.com/ekatrukha/BigScopeScatter/wiki/Installation) it and figure out the rest.
